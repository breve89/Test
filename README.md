# Fan HQ

A personal dashboard for the topics I follow: **NFL (Patriots), Star Wars, video games, workouts and WWE**.

## What's inside

- **Home**: live countdowns to the Patriots' next game, the next WWE premium live event and the GTA 6 launch, plus the latest podcast episodes (What Do You Want to Talk About? with Cody Rhodes, The Gronk & Jules Show, Games with Names).
- **NFL**: weekly pick'em picks with win probabilities and reasoning, league leaders, team stats, standings for any team, scores and schedule, team news and trivia.
- **Star Wars**: news, a lightsaber workshop (build, ignite and save sabers) and trivia.
- **Video Games**: PC, PlayStation, Xbox and Nintendo news and current deals, plus trivia.
- **Workouts**: log sets, reps and weight; see gym-day streaks, a calendar heatmap, progress charts and personal records.
- **WWE**: news, the upcoming PLE match card, show schedule and trivia.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The whole app: layout, styles and logic in one page |
| `feed.js` | News, deals, scores, picks, stats and podcasts. Edit this file to update content |

## Run it

Open `index.html` in a browser. To host it, turn on **GitHub Pages** (Settings → Pages → deploy from the `main` branch, root folder).

Workout logs, saved lightsabers and trivia best scores are stored in your browser (localStorage) when the page runs outside Claude.

News summaries link to their original sources (ESPN, NFL.com, Boston Globe, WWE.com, StarWars.com, Xbox Wire, Push Square and others).
